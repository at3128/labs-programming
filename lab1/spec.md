# Специфікація: бібліотека

## Сутності та атрибути

- Book (книга): id (ідентифікатор), title (назва), year (рік видання), isbn (ISBN)
- Copy (примірник): id (ідентифікатор), inventory_number (інвентарний номер)
- Author (автор): id (ідентифікатор), name (ім'я), country (країна)
- Reader (читач): id (ідентифікатор), name (ім'я), phone (телефон), registration_date (дата реєстрації)
- Loan (видача): id (ідентифікатор), issue_date (дата видачі), planned_return_date (планова дата повернення), actual_return_date (фактична дата повернення)

## Зв'язки

- Book — Author: багато-до-багатьох
- Book — Copy: один-до-багатьох
- Copy — Loan: один-до-багатьох
- Reader — Loan: один-до-багатьох
- Loan є окремою сутністю, бо має власні атрибути (дати)

## Критерії прийняття

- Кожна сутність має назву і принаймні один атрибут.
- Кожна сутність має атрибут id, і всі id мають тип int.
- Кожен зв'язок має вказану кардинальність.
- Якщо зв'язок багато-до-багатьох має власні атрибути, він оформлений окремою сутністю. Якщо не має, окремої сутності немає.
- Кожна властивість записана в тій сутності, від id якої вона залежить. Жодна властивість не належить до іншої сутності (це відповідає 3NF).
- Назви сутностей і атрибутів у er-diagram.md такі самі, як у spec.md.
